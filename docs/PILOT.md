# ซ้อมและทดลองใช้จริง (ระยะที่ 7)

## ก. ซ้อมเองบน production ก่อนใช้กับนิสิต

ใช้คอมพิวเตอร์ 1 เครื่องสำหรับหน้าอาจารย์ และมือถือ 1 เครื่องสำหรับหน้านิสิต (บัญชีนิสิตทดลอง 1 บัญชี)

- [ ] **คอม:** เข้า `/admin` ด้วย Google แล้วเห็นเมนู 3 อย่าง
- [ ] **มือถือ:** เข้าระบบด้วยบัญชีนิสิตทดลอง เห็นแถบเตือนเปลี่ยนรหัส และสถานะ “อัปเดตอัตโนมัติ”
- [ ] **คอม:** สร้างโจทย์ทดลอง (ชื่อขึ้นต้น “ซ้อม”) แล้วกด **เปิดรับคำตอบ**
- [ ] **มือถือ:** เห็นโจทย์ขึ้นมาเองภายในราว 1–2 วินาที **โดยไม่รีเฟรช**
- [ ] **มือถือ:** ส่ง SQL → ยืนยัน → เห็นใบยืนยัน “ส่งแล้ว” พร้อมลำดับที่ 1
- [ ] **คอม:** หน้ารายละเอียดโจทย์ขึ้นผู้ส่งเองโดยไม่รีเฟรช
- [ ] **มือถือ:** พับจอ 1 นาที แล้วเปิดกลับมา หน้ายังอัปเดตถูก
- [ ] **คอม:** กด **ปิดรับคำตอบ** แล้ว**มือถือ**ขึ้น “ปิดรับคำตอบแล้ว” เอง
- [ ] **คอม:** ให้คะแนนด้วยปุ่มลัด **ดี** แล้ว **ประกาศผล** และกด **คัดลอกลิงก์**
- [ ] **มือถือ:** แท็บ **ประวัติของฉัน** เห็น “ได้บางส่วน” พร้อมคะแนน
- [ ] **เบราว์เซอร์ที่ไม่ได้ล็อกอิน:** เปิดลิงก์อันดับได้ เห็นรหัสแบบปิดบางส่วน ไม่มีชื่อ ไม่มี SQL
- [ ] **คอม:** **ส่งออก CSV** และ **สำรองข้อมูลทั้งหมด (zip)** เปิดได้ ภาษาไทยถูก
- [ ] **คอม:** ลบโจทย์ “ซ้อม” (พิมพ์ชื่อยืนยัน)
