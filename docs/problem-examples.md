# ตัวอย่างการกรอกโจทย์ (หน้าอาจารย์ → โจทย์ → สร้างโจทย์ใหม่)

คัดลอกเนื้อหาในกรอบไปวางในช่องที่ตรงกันของฟอร์ม ใช้ปุ่ม **ตัวอย่าง** ข้างช่อง markdown เพื่อดูว่านิสิตจะเห็นอย่างไร

> ตัวอย่างใช้ฐานข้อมูล `world` ของ MySQL ตัวเลขในช่อง “ตัวอย่างผลลัพธ์” ควรได้จากการรันคำสั่งเฉลยจริงใน HeidiSQL แล้วคัดลอกมาไม่กี่แถว

---

## ตัวอย่างที่ 1 — WHERE + ORDER BY (ลำดับต้องตรง)

**ชื่อโจทย์**

~~~text
เมืองในประเทศไทยที่มีประชากรเกิน 150,000 คน
~~~

**คำอธิบาย (markdown)**

~~~markdown
แสดง **ชื่อเมือง** และ **จำนวนประชากร** ของเมืองในประเทศไทย (`CountryCode = 'THA'`)
ที่มีประชากร **มากกว่า 150,000 คน**

- เรียงจากประชากร **มากไปน้อย**
- ตั้งชื่อคอลัมน์ผลลัพธ์เป็น `Name` และ `Population`
~~~

**โครงสร้างตาราง (markdown)**

~~~markdown
ตาราง `city`

| คอลัมน์ | ชนิด | ความหมาย |
| --- | --- | --- |
| ID | int | รหัสเมือง |
| Name | char(35) | ชื่อเมือง |
| CountryCode | char(3) | รหัสประเทศ เช่น `THA` |
| District | char(20) | จังหวัด/เขต |
| Population | int | จำนวนประชากร |
~~~

**ตัวอย่างผลลัพธ์ (markdown)** — ใส่แค่ไม่กี่แถวแรก

~~~markdown
| Name | Population |
| --- | --- |
| Bangkok | 6320174 |
| Nonthaburi | 292100 |
| Nakhon Ratchasima | 181400 |
| … | … |
~~~

| ช่อง | ค่า |
| --- | --- |
| คะแนนเต็ม | `10` |
| dataset_name | `world` |
| ลำดับแถวต้องตรง | ✅ ติ๊ก (โจทย์สั่งให้เรียง) |

**คำสั่งเฉลย (นิสิตไม่เห็น)**

~~~sql
SELECT Name, Population
FROM city
WHERE CountryCode = 'THA' AND Population > 150000
ORDER BY Population DESC;
~~~

## ตัวอย่างที่ 2 — GROUP BY + HAVING (ลำดับไม่สำคัญ)

**ชื่อโจทย์**

~~~text
ประเทศที่มีภาษาราชการมากกว่า 2 ภาษา
~~~

**คำอธิบาย (markdown)**

~~~markdown
แสดง **รหัสประเทศ** และ **จำนวนภาษาราชการ** ของประเทศที่มีภาษาราชการ (`IsOfficial = 'T'`)
**มากกว่า 2 ภาษา**

- คอลัมน์ผลลัพธ์: `CountryCode`, `official_count`
- เรียงลำดับอย่างไรก็ได้
~~~

**โครงสร้างตาราง (markdown)**

~~~markdown
ตาราง `countrylanguage`

| คอลัมน์ | ชนิด | ความหมาย |
| --- | --- | --- |
| CountryCode | char(3) | รหัสประเทศ |
| Language | char(30) | ชื่อภาษา |
| IsOfficial | enum('T','F') | เป็นภาษาราชการหรือไม่ |
| Percentage | float(4,1) | สัดส่วนผู้ใช้ภาษา (%) |
~~~

**ตัวอย่างผลลัพธ์ (markdown)**

~~~markdown
| CountryCode | official_count |
| --- | --- |
| CHE | 4 |
| ZAF | 4 |
| … | … |
~~~

| ช่อง | ค่า |
| --- | --- |
| คะแนนเต็ม | `10` |
| dataset_name | `world` |
| ลำดับแถวต้องตรง | ⬜ ไม่ติ๊ก |

**คำสั่งเฉลย (นิสิตไม่เห็น)**

~~~sql
SELECT CountryCode, COUNT(*) AS official_count
FROM countrylanguage
WHERE IsOfficial = 'T'
GROUP BY CountryCode
HAVING COUNT(*) > 2;
~~~

## เคล็ดลับการเขียน markdown

| ต้องการ | พิมพ์ |
| --- | --- |
| ตัวหนา | `**ข้อความ**` |
| ชื่อคอลัมน์/คำสั่ง | `` `CountryCode` `` |
| รายการ | ขึ้นบรรทัดด้วย `- ` |
| ตาราง | `\| หัว \| หัว \|` ตามด้วยบรรทัด `\| --- \| --- \|` |
| บล็อกโค้ดหลายบรรทัด | ครอบด้วย ```` ``` ```` บรรทัดบนและล่าง |

- **ลำดับแถวต้องตรง:** ติ๊กเฉพาะโจทย์ที่สั่งให้ `ORDER BY` ใช้กับตัวตรวจอัตโนมัติในอนาคต
- **คะแนนเต็ม:** ใส่ทศนิยมได้ 2 ตำแหน่ง เช่น `2.5`
- **สร้างไว้ล่วงหน้าได้:** นิสิตยังไม่เห็นจนกว่าจะกด **เปิดรับคำตอบ**
