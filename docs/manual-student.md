# คู่มือนิสิต: SQL Quick Quiz

เว็บ: **https://sqlquickquiz.vercel.app**

ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ทดลองคำสั่งบนเครื่องตัวเองให้มั่นใจก่อน (MySQL + HeidiSQL) แล้วค่อยนำ SQL มาส่ง

## 1. เข้าสู่ระบบ

1. เปิดเว็บ แล้วกรอก **รหัสนิสิต** (ตัวเลข 8 หลัก)
2. **รหัสผ่าน**ครั้งแรกคือรหัสนิสิตของตัวเอง
3. กด **เข้าสู่ระบบ**

- ให้เข้าระบบ**ก่อนอาจารย์เปิดโจทย์** และไม่ต้องออกจากระบบหลังเลิกเรียน ถ้าใช้เครื่องของตัวเอง ครั้งต่อไปจะเข้าได้ทันที
- ถ้าเห็น “กำลังรอคิว ไม่ต้องกดซ้ำ…” แปลว่าเพื่อนทั้งห้องกำลังเข้าพร้อมกัน ระบบจะลองให้เองภายในไม่กี่วินาที
- ถ้าเห็น “มีการเข้าสู่ระบบจำนวนมากเกินไป” ให้รอ 5 วินาทีแล้วกดใหม่
- ถ้ากรอกรหัสผิดหลายครั้ง บัญชีไม่ถูกล็อก กรอกใหม่ได้เรื่อย ๆ

## 2. เปลี่ยนรหัสผ่าน (แนะนำ)

ถ้ายังใช้รหัสผ่านเริ่มต้น จะมีแถบสีเหลืองเตือนทุกครั้งที่เข้าใช้

1. กดเมนู **บัญชี** (มุมขวาบน) → **เปลี่ยนรหัสผ่าน**
2. กรอก **รหัสผ่านเดิม**, **รหัสผ่านใหม่** (อย่างน้อย 8 ตัวอักษร) และ **ยืนยันรหัสผ่านใหม่**
3. กด **บันทึก** แล้วแถบเตือนจะหายไป

**ทำไมควรเปลี่ยน:** เพื่อนที่รู้รหัสนิสิตของเราจะเข้าระบบแทนแล้วส่งคำตอบแทนเราได้ และส่งได้ครั้งเดียว แก้ไม่ได้

**ลืมรหัสผ่าน:** แจ้งอาจารย์ให้รีเซ็ต รหัสผ่านจะกลับเป็นรหัสนิสิต

## 3. ส่งคำตอบ

แท็บ **โจทย์ปัจจุบัน** จะแสดงโจทย์**ทันทีที่อาจารย์เปิด** ไม่ต้องรีเฟรชหน้า

1. อ่านโจทย์ โครงสร้างตาราง และตัวอย่างผลลัพธ์
2. ทดลองคำสั่งบนเครื่องตัวเองจนได้ผลถูก
3. คัดลอก SQL มาวางในช่อง **คำสั่ง SQL ของคุณ** แล้วกด **ส่งคำตอบ**
4. หน้าต่างยืนยันจะขึ้นมา: **ส่งได้ครั้งเดียว แก้ไม่ได้** ตรวจให้แน่ใจแล้วกด **ยืนยันส่ง**
5. เมื่อเห็นกล่องสีเขียว **ส่งแล้ว** พร้อมเวลาและ**ลำดับที่** แปลว่าระบบบันทึกเรียบร้อย

- เวลาส่งใช้เวลาของเซิร์ฟเวอร์ ไม่ใช่นาฬิกาของเครื่องเรา ลำดับที่คือลำดับการส่งของทั้งห้อง
- เมื่ออาจารย์ปิดรับ โจทย์จะขึ้นว่า **ปิดรับคำตอบแล้ว** และส่งไม่ได้อีก
- ถ้าเน็ตหลุดตอนกดส่ง ให้กดใหม่ได้ ถ้าส่งเข้าไปแล้ว ระบบจะแสดงใบยืนยันเดิม ไม่มีทางส่งซ้ำ
- **ข้อความสถานะมุมบน:**
  - “อัปเดตอัตโนมัติ” แปลว่าปกติ
  - “กำลังเชื่อมต่อใหม่…” แปลว่าเน็ตสะดุด ระบบจะต่อกลับเอง ถ้าค้างนานให้รีเฟรชหน้า
- **พับจอมือถือหรือสลับแอป:** กลับมาที่หน้าแล้วข้อมูลจะอัปเดตเอง

## 4. ดูผลคะแนน

แท็บ **ประวัติของฉัน** แสดงทุกข้อที่เคยส่ง เรียงล่าสุดก่อน

| สถานะ | ความหมาย |
| --- | --- |
| รอตรวจ | อาจารย์ยังไม่ประกาศผล |
| ถูก / ได้บางส่วน / ผิด | ผลและคะแนนหลังประกาศผล อาจมีความเห็นจากอาจารย์ด้วย |

อาจารย์แก้คะแนนหลังประกาศได้ หน้านี้จะแสดงค่าล่าสุดเสมอ

หน้าอันดับที่อาจารย์แชร์ เรียงตามคะแนนเป็นค่าเริ่มต้น (คะแนนเท่ากัน ใครส่งก่อนได้อันดับดีกว่า) และกดสลับเป็น “เรียงตามลำดับส่ง” ได้ รหัสนิสิตแสดงเพียงบางส่วน ไม่มีชื่อและ SQL

## 5. ใช้เครื่องส่วนกลาง (ห้องแล็บ)

**ทุกครั้งที่ใช้เสร็จ:** กด **บัญชี** → **ออกจากระบบ** ถ้าไม่ออก คนถัดไปจะใช้บัญชีของเราส่งคำตอบหรือเปลี่ยนรหัสผ่านได้

## ปัญหาที่พบบ่อย

| อาการ | ทำอย่างไร |
| --- | --- |
| ไม่เห็นโจทย์ | รออาจารย์เปิด ถ้าอาจารย์เปิดแล้วยังไม่เห็น ให้รีเฟรชหน้า |
| “บัญชีนี้ถูกปิดใช้งาน” | ติดต่ออาจารย์ |
| ส่งไม่ได้: “ปิดรับคำตอบแล้ว” | หมดเวลาส่งข้อนั้นแล้ว |
| ส่งผิดข้อหรือพิมพ์ SQL ผิด | แก้ไม่ได้ แจ้งอาจารย์ |
