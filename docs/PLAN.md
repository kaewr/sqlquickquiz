## ระยะที่ 7.2 – อันดับตามคะแนน และเงื่อนไขประกาศผล (ผู้ใช้สั่ง 2026-11-11, ทำก่อนทดลองตอน 1)

## อนาคต – ตรวจอัตโนมัติ (หลังทำ `sql-grader` เสร็จ)

- `grading-worker` ใน Docker บนเครื่องอาจารย์ (MySQL 8.4 + worker Python ที่เรียก `sql-grader`)
- ปุ่ม “ตรวจอัตโนมัติ” ในหน้ารายละเอียดข้อ → สร้าง grading_jobs → worker รับผ่าน Realtime → เขียน results (source = auto) โดยไม่ทับผลที่ source = manual → หน้าเว็บแสดงความคืบหน้า
- หน้าเว็บแจ้งเตือนเมื่อ worker ไม่ได้เปิดอยู่
- จะเพิ่มรายละเอียดระยะนี้เมื่อพร้อม
